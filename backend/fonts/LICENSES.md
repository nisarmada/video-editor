# Bundled fonts (OFL)

TTFs in this directory come from the [Google Fonts](https://fonts.google.com) repository (SIL Open Font License 1.1). See `OFL.txt` in this folder for the full license text.

| File | Family |
|------|--------|
| Montserrat-Variable.ttf | Montserrat |
| Poppins-Regular.ttf | Poppins |
| Inter-Variable.ttf | Inter |
| Oswald-Variable.ttf | Oswald |
| Anton-Regular.ttf | Anton |
| BebasNeue-Regular.ttf | Bebas Neue |
| Bangers-Regular.ttf | Bangers |

The renderer passes `fontsdir` to ffmpeg’s `subtitles` filter so libass can resolve these faces.
